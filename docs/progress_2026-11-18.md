## 3. Design decisions (all user-confirmed)

### Toolchain and project
| Decision | Choice | Reason |
|---|---|---|
| Generator toolchain | Plain `pxr` + `numpy` + `pyyaml`; no Kit at generation time | Fast, headless, unit-testable; core USD covers meshes, capsules, physics and semantics schemas |
| Isaac version | Dedicated conda env `bamboo` with Isaac Sim 6.2 | Brief names 6.2 as the target; acceptance tests should run against it |
| Config format | YAML; each number is a constant or a distribution spec (`constant`, `uniform`, `truncnormal`, `lognormal`); guesses tagged `# ASSUMPTION:` inline | Brief principle 4: every number in config, as distributions; easy to replace with field data |

### Culm
| Decision | Choice | Reason |
|---|---|---|
| Diameter ↔ height | Sample base diameter first, then `length = a + b·d + N(0, noise_sd)`, clamped | Taller culms are thicker (brief); trivially refit from field measurements |
| Sizes | Diameter truncnormal mean 8.8 cm, sd 0.8, range 7.5–10 cm; length `a=3.4, b=56, noise 0.35`, clamp 6.5–10 m | Brief's "young plants, 3–4 in". Kept as-is until the field trial even though some culms exceed 9 m |
| Node rings | Mesh geometry (cosine-shaped radial bulge, 3–6 % of radius, 2 cm wide) in the bottom 3 m only | Lidar ray-traces render geometry; sensors look at the lower 3 m |
| Mesh resolution | 16 sides inside the 3 m detail zone, 8 above, stitched with a triangle band | Spend detail where sensors look; ~2.2–2.6k tris per culm |
| Taper | Piecewise-linear control points `(h/L, d/d_base)`: near-cylindrical lower third, accelerating taper, tip 18 % | Brief: "not a straight cone"; values stored in ground truth |
| Internodes | Longest internode truncnormal ~45 cm; profile short at base → longest mid-culm → shorter at tip; ±6 % noise | Brief: 40–50 cm, increasing then decreasing |
| Lean and bow | Lean angle + azimuth; bow = quadratic horizontal offset along the lean azimuth | Planar curve → exact rotation-minimizing frames, no twist |
| Cut point | Default: 5 cm above the first node at or above 0.30 m (alternative mode: fixed distance above base) | Placeholder until the grower confirms harvest cut location |
| "length" vs "height" | `length` = along the culm axis; vertical `height` also recorded | Lean and bow make height ~0.5–1 % shorter than length |

### Clump
| Decision | Choice | Reason |
|---|---|---|
| Culm count | truncnormal **mean 50, sd 8, range 35–70** (culms + stumps) | Matched to a Google Maps photo of a Frostproof clump (earlier: 20, then 25) |
| Footprint radius | Grows with count: `R = 0.2 + 0.008571·N + N(0, 0.04)`, clamped **0.5–0.8 m** | Tight base seen in the photo (earlier: 0.6–1.1 m, then 1.0–1.3 m) |
| Base arrangement | Even spread over the area (dart throwing), `edge_bias` knob default 0 | No data on edge bias yet |
| Min gap between culm surfaces | **1 cm** (at ground and along the full length) | Culms nearly touching at the base in the photo (earlier: 3 cm) |
| Lean | Outward from center: `lean = culm lean draw + 18°·(r/R)`, cap **35°**, azimuth jitter ±20° | Strong vase/fan shape in the photo (earlier: +6°, cap 20°) |
| Bow | Uniform **5–15 %** of length | Outer culms arch outward in the photo (earlier: 0–6 %) |
| Overlap handling | Redraw lean up to 20×, then straighten (scale lean and bow by 0.8 per step) | Keep every culm; deterministic; adjustment logged in ground truth |
| Near-vertical culms | Accepted as-is | Plausible in a real clump |
| Stumps | ~15 % of slots, 0.15–0.5 m, flat closed top 3 cm above the highest node below the sampled height | Harvested culms are in the robot's perception zone |
| Stump labeling | Semantic class `culm` + `is_stump` flag in ground truth | User choice |

## 4. Code written

```
bamboo_bot/
  .gitignore                     out/, __pycache__/, .pytest_cache/
  configs/grove_default.yaml     every parameter, documented, ASSUMPTION-tagged
  bamboo_grove/
    __init__.py
    distributions.py             Dist specs + seeded sampling (rejection for truncation)
    config.py                    YAML -> validated frozen dataclasses (CulmConfig, MeshConfig, ClumpConfig)
    culm.py                      CulmSpec: centerline, frames, radius (taper + node bulges), nodes,
                                 cut point, stumps, ground_truth(); sample_culm(), make_stump()
    mesh.py                      swept-tube mesh: ring stations, 16->8 stitching, end caps
    clump.py                     build_clump(): count, radius, stumps, base placement,
                                 outside-in lean assignment with capsule-chain clearance checks
    preview_culm.py              dev tool: N culms in a row -> .usda
    preview_clump.py             dev tool: one clump -> .usda (stumps tinted brown)
  docs/progress_2026-11-18.md    this file
```

Key implementation details:
- **Determinism:** all randomness comes from `numpy.random.Generator`s seeded via `SeedSequence`. Draw order is fixed. Stump height is drawn whether or not a slot becomes a stump, so changing the stump rate doesn't shift other draws.
- **Mesh:** points are stored relative to each culm's base; the culm's position sits on its parent Xform (precision across a large grove). `subdivisionScheme = none`. Faces wind CCW from outside (outward normals). The base extends 5 cm below z=0 so future uneven terrain shows no gap.
- **No intersections:** each culm is a 12-segment capsule chain with conservative radii (taper is non-increasing, bulge amplitude added). All culms start upright; leans are assigned **outside-in**. Upright is always collision-free, so the result never intersects.

## 5. How to run

```bash
conda activate bamboo
cd ~/nick/bamboo_bot

# a few single culms in a row
python -m bamboo_grove.preview_culm  --config configs/grove_default.yaml --seed 1 --count 6 --out out/culms.usda

# one clump
python -m bamboo_grove.preview_clump --config configs/grove_default.yaml --seed 1 --out out/clump.usda
```

View in Isaac Sim 6.2:
```bash
conda activate bamboo
export LD_PRELOAD=/lib/aarch64-linux-gnu/libgomp.so.1
isaacsim
```
Then File → Open → `out/clump.usda`. Press F to frame, Alt+drag to orbit. For light, use Create → Light → Dome Light, or the viewport's light-bulb menu → Camera Light. **Don't save lights into the grove asset**; test scenes will reference it instead.

`.usda` = text USD (human-readable); `.usdc` = binary USD (faster). The final `grove.usd` will likely be binary.

| Check | Result |
|---|---|
| Determinism | Same seed → byte-identical `.usda`, run twice, and across the 6.0.1 and 6.2 envs |
| Mesh validity | 20 culms: watertight, consistent winding, positive volume (outward normals) |
| Culm sizes (seed 1, 6 culms) | Diameter 7.9–10.0 cm, length 7.86–9.58 m, 22–29 nodes, cut point 0.35–0.42 m above ground |
| Clump intersections | None, re-checked with 60-segment capsule chains (5× builder resolution) |

| Lean adjustments | 89 % none, 10 % redrawn, 1 % straightened |
| Lean vs position | Mean lean 8.6° (inner third), 13.5° (middle), 19.5° (outer) |
| Cost | ~0.33 s and ~107k triangles per clump |

### Issue found and fixed
With the dense clump, ~50 % of culms were being straightened to vertical. The cause was the **order** of lean assignment: inner culms were leaned first while outer neighbors were still upright and in the way. Experiments ruled out azimuth jitter, bow and random base lean as the cause. The order was changed to **outside-in**, and straightening dropped to 1 %.

## 8. Known gaps and open questions

1. **Foliage:** branches and leaves make up much of the photo's fullness. They are out of scope for v0 (brief); there will be a hook only. The photo shows some branching below 2 m, inside the sensors' view.
2. **Diameter:** culms in the photo look thinner (roughly 3–6 cm) than the configured 7.5–10 cm. The user kept 7.5–10 cm for now.
3. **Triangle budget:** ~107k tris per clump → a 4 × 15 grid would be ~2,600 live culms and ~6.4M triangles, about 2× the brief's ~1,200-culm budget. Options: fewer sides per culm, a smaller grid, or measure first in the Isaac harness.
4. **Clump spacing:** at 8 ft (2.44 m) in-row spacing, bases have room (1.0–1.6 m wide), but tops fan out to ~3 m across by 3 m height, so neighbors in a row will interleave above ~2 m. This is the first layout decision.
5. **All botanical numbers are placeholders** until the field trial (diameter, height, internodes, culm count, clump width, lean).
